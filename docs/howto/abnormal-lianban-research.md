# 严重异动研究报告 v2

生成入口：`python tools/generate_abnormal_lianban_study.py`。
固定截止日可加 `--as-of 2026-10-28`；先有证据快照后可用 `--offline` 完全离线重放。
输出仍为 `output/abnormal_lianban_study/abnormal_lianban_study.html` 和同名 Markdown。
报告不是自动更新页面，也未接入定时任务或发布流程。

## 观察口径

- 主样本为创业板300/301与沪深普通主板；当前ST名称排除，历史ST/IPO资格不完整，不能冒充交易所完整名单。
- 偏离值为个股累计收益减对应指数累计收益。固定N日需N+1个收盘值；同时检查1…N日子窗口。指数分别为上证A股、深证A股、创业板综合指数。
- 历史计算固定使用前复权序列。缺失留未知；不因未来行缺值切换历史原始/复权口径。当前复权缓存仍非完整历史时点快照。
- 10日80—100、30日180—200为“距阈值20个百分点”的研究预警区。数值越线不替代公告确认，缺少完整公告重置历史须显式说明。
- 首次预警事件与首次越线事件使用不同观察日起算；两组有重叠，不能相加成独立样本。
- 横盘历史从首次预警后的首轮非涨停日开始，恰好经过2/3/5个完整交易日再判断。涨停未知、缺价、缺指数不当作横盘。
- 横盘入选只用当时信息：全部非涨停、收盘区间不超过15%、收盘路径回撤小于10%、保持MA5。收益从该观察日重新起算5/10日，包含后续失败样本。
- 当前匹配仅同上市板别/同10或30日窗口/同横盘日数，按当时偏离值及区间幅度筛选；排除本股票、未成熟标签，一只历史股票最多一条。少于5只不显示预测分位。
- 全市场主板/创业板上涨不是机器人、医药等同题材共振，报告明确同题材证据待核。

## 案例

凡拓数创严重异常公告和重点监控，莱美药业普通异动公告分别有来源；案例日线单独从腾讯同批未复权OHLC取得并与本地逐日收盘对账。
案例涨停价按前收盘×1.20四舍五入到分；莱美10/16最高9.76而收9.75属于触板未封。
公告后3/5/10日严格区分成熟与未成熟。收益是路径描述，未验证真实入场成交、成本或T+1约束。

## 产物

- `study_payload.json`：HTML/Markdown共用结构化输入。
- `abnormal_threshold_events.csv`、`first_crossing_events.csv`：两种事件时钟。
- `sideways_landmarks.csv`、`sideways_summary.csv`：含失败的2/3/5日观察样本与分母。
- `current_case_analysis.csv`、`analog_matches.csv`：当前条件分支与历史匹配明细。
- `index_snapshot.json`、`alert_snapshot.json`、`target_ohlc_snapshot.json`：可离线回放的来源响应。
- `input_manifest.json`、`verification.json`：输入哈希、唯一性及正式输入未改校验。
- `legacy_v1/`：旧页面备份。旧的赢家筛选上涨空间不能继续作为预测引用。

开盘啦提醒匿名请求即可；不需要他人账号凭据。`Many_Num`为多次异动个股计数，非提醒行数；行[11]为触发参考价，行[8]为当日/次日累计触发涨幅，不能解释成现价剩余上涨空间。
