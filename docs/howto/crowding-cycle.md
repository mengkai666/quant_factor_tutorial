# 抱团周期：证据核验版

## 使用

运行 `python tools/build_crowding_report.py --as-of 2026-10-08 --link-local`。

默认全离线、不发布、不发邮件、不下单；`--refresh-reference-quotes` 仅向腾讯证券请求18只参考个股日线，保存独立 `data/crowding_reference_quotes.json`。局部请求失败保留旧数据并记录错误；整体失败不覆盖缓存。

历史重跑会保留更晚日期的研究latest；抱团子页与主报告日期不一致时禁止伪装归档。

主应用在报告归档阶段调用 `build_crowding_report(latest_date)`，与请求日期相同的独立子页写入站点 `crowding` 目录。工具的 `--link-local` 仅更新本地主报告/导航入口，不修改历史主报告归档或推送远程站点。并发存在的另一份 `baotuan_cycle` 模块原样保留，本模块是独立的证据核验版。

## 数据与认识边界

- 请求日、全市场价格日、涨停日、广度日、补充个股日各自显示。2026-10-08这期初次检查时全市场缓存只到9/30；工作区后续更新后，最终报告的全市场价格、涨停、广度及18只参考个股均截止10/8。任何重新生成都以页内逐源时钟为准，不因单项更新而隐藏其余缺口。
- 复盘窗口为请求日减两个自然月；本期2026-08-08—2026-10-08，第一实际交易日8/10。行情预热最多向前60个自然日。
- 图1/2未标年份，按图3的2026-10-08时间解释；图2/3是一份重复观点，非独立佐证。科技红叉不解读成确定已失效，更不形成永久排除名单，只是不列为确认主线。
- 断板不等于整个抱团瓦解；固定旧核心群体普遍失效才构成价格瓦解代理。至少2日止跌仅标“出清观察”，不声称资金已出清。
- 近岸蛋白在9月中旬已有趋势；不是9/28低位首发。尚水智能9/28下跌、9/29走强；被列入试错池和通过验证必须分开。
- 题材类别来自截图。没有持仓/逐笔/资金流证据，不把同涨共振称为机构抱团，也不证明一只股票的钱流到另一只。
- 新股、ST、科创/创业板、主板、北交所涨跌幅制度不同；高度表只是原缓存对照，不可据板数直接比较风险或交易机会。

## 计算

价格只用全市场缓存的 `close_qfq`，不以原始价/旧口径静默补值。缺交易日保留空值；收益计算不进行前向填充。

滚动候选使用当时及此前的价格：5日收益>4%、20日收益>8%、近5日至少2天5日收益处于前15%。相对分 = 40×5日百分位 + 40×20日百分位 + 4×持续天数。连续两天排名第一才记录“代理换位”。它不是截图接替链的验证、不是概率、不是回测胜率。

固定旧篮子：至少60%的成员距20日收盘高点回撤10%以上且低于MA5，同时当日收益中位数<-2%才标为“瓦解”代理；后续所有成员至少2日不创新近3日收盘低点，才能升为“出清观察”。缺一个成员的必要数据就阻断升级；不会删除失败成员让篮子变好看。

试错检查包括：旧团止跌、当日市场涨跌家数改善、候选价格持续性、量能/承接/可成交性。只有价格指标可从本模块直接判断，缺失项明确标识，不直接输出交易确认。

区间收益从起始日前一交易日收盘起算。没有基准日（如新上市沈鼓）则不计算完整区间收益；区间最大回撤仅反映可见收盘价，盘中风险更高。图表首个可见收盘归一化100，缺失处断线。

## 研究与事前验证

2026-10-08之前的报告不会加载这天提供的截图具体股票名单，算法也不使用该名单排名。所有输入先按请求日截断；未来行不能改变历史结果。

当前历史缓存不是严格的PIT证券主数据或PIT复权序列，仍存在复权修订、存活样本、流动性和研究者选样偏差。条件战法尚未做含手续费、滑点、T+1、跳空、涨跌停不能成交的严格回测，所以不生成收益保证、固定买卖价或仓位。

下一步如要验证策略，应保存当时真实候选快照、固定失效规则，按下一可成交时点模拟，保留失败/未成交/未结束事件，并做样本外与阈值敏感性检验。

## 文件与测试

- `src/crowding_cycle.py`：归一化、时钟、滚动代理、参考篮子、阶段、事件与条件战法。
- `src/crowding_view.py`：无外部脚本的HTML/SVG报告、JSON与Markdown导出。
- `tools/build_crowding_report.py`：CLI、可选个股刷新、本地入口更新。
- `tests/test_crowding_cycle.py`：防未来数据、价格口径、缺失成员、过期截面、个股/全市场分时钟、空数据、HTML转义及发布入口测试。

验证命令：`python -m pytest tests/test_crowding_cycle.py tests/test_publish_site.py tests/test_publication_gate.py -q`。
