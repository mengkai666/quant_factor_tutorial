# 多板块盘后观察：新版报告

## 读什么

多板块观察作为独立子页，包含市场事实与变化、前5个有效题材板块各3只重点股、近期多板轨迹和次日观察要点。原主报告与原独立看板恢复原布局；新版内容不再覆盖它们。

- 板块榜依据权威日快照的主线标签，按涨停家数、连板家数、最高板排序；这是涨停题材热度，不是资金净流入排名，也不是公司的主营行业分类。
- 板块内按连板高度、成交额、首次封板时间、代码稳定排序；ST/退市标签个股不进入板块三股。只有可核验同日参考价的股票参与排序，缺少有效样本时不虚构第三只。
- 近期多板看最近5个交易日：出现过2板以上，或窗口内累计至少2次涨停。当前连板、窗口最高板和涨停次数分别统计。首板不称为多日连板。
- 多板主表默认展开20只，其余可展开查看，JSON和CSV保留全部。ST在这一专题保留并标识；不在本日完整涨停池称“今日未涨停”，不擅自说它跌停、亏损或已成交。
- 参考价来自对应收盘日。近5日涨幅用交易日历上精确的两个前复权价格端点，不用相邻日补位；它是价格变化，不是策略收益。

## 本地生成（不发邮件、不发布、不下单）

在仓库根目录运行：

~~~powershell
python -B -X utf8 tools/render_research_brief.py --output-dir output/research_briefs
~~~

默认读取本地最新权威日快照。指定历史日或审计：

~~~powershell
python -B -X utf8 tools/render_research_brief.py --date 2026-09-07 --output-dir output/research_briefs
python -B -X utf8 tools/render_research_brief.py --audit output/audit/2026-09-07.json --output-dir output/research_briefs
~~~

加 --fetch-ohlc 才会补取板块重点股与多板主表所需的同日未复权OHLC。其他参数：--max-sectors（默认5）、--stocks-per-sector（默认3）、--recent-window（默认5）、--recent-limit（默认20，仅控制主表展开数量）。

可用 --snapshot-dir、--price-slices-dir、--calendar-cache、--raw-bar-cache-dir 指向独立输入包；不会为了展示股票而写入“验证通过”。未收盘、未来日、明显错日/身份/价格冲突会拒绝输出，不覆盖上一份有效报告。

## 输出文件

- research_brief_日期.html：新版正文。
- research_brief_日期.json：所有页面共用的研究数据模型。
- sector_watchlist_日期.csv：板块重点股。
- recent_boards_日期.csv：完整近期多板列表（包含默认折叠行）。

新CSV标明purpose=research_observation。它们不是旧focus_pool.csv，不改变交易许可、真实成交、持仓或收益记录的语义。

## 主页面与子页面

- 主页面：output/主线强度追踪.html，保留原有完整图表和布局，顶部增加“多板块观察”入口。
- 子页面：output/research_briefs/research_brief_日期.html；同目录latest.html为最新子页。子页提供“返回主报告”链接，JSON和两种CSV保留在同目录。
- 原独立看板仍由原看板渲染器生成，不再被研究简报替换。
- 正常主脚本会生成子页并挂上入口；子页生成失败时，不因此中断原主报告。CLI默认返回主报告目标为output/主线强度追踪.html，可用--parent-report指定其他主报告。CLI只生成子页，不改写主页面。
- 发布时主报告归档仍在reports/，看板仍在dashboards/；研究子页单独归档到research_briefs/，首页另加入口。归档主页面指向同日子页，子页返回同日主报告，避免不同目录深度造成链接失效。
- 发布日期比对只忽略本模块自有的导航标记；图表、正文或完整性元数据变化仍不能被当作同一份报告。

注意：完整主脚本保留原有数据跑批及按已有配置执行的归档/邮件功能。本次只恢复本地页面及修改后续生成逻辑，没有实际发布或发送邮件。
