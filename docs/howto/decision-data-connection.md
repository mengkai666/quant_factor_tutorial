# 事件数据接通与盘中采集

## 先分清四种状态

- **已有原始行情，但还未解释成策略字段**：例如炸板次数已经存在，旧报告却没有“曾炸板”布尔字段。本轮用带规则版本和原值证据的解释层解决，不重写原始观测。
- **收盘样本完整，但没有全市场事件总体**：收盘涨停池不包含炸板后未回封的全部股票，不能拿它计算全市场炸板率或回封成功率。
- **盘中时点没有实际观察**：盘后报价、当前报价不能回填成已经过去的竞价、9:35或10点观察。
- **策略未验证或本次不适用**：独立验证报告缺失、研究/观察分支、AI服务失败分别说明；它们不是基础行情缺失，也不会通过修改显示文案获得交易许可。

## 1. 用已有数据解释事件

在仓库根目录执行：

~~~powershell
python -X utf8 tools/connect_limit_events.py --date 2026-09-07 --no-fetch --output-dir output/event-connection
~~~

这只读原始事件归档与已缓存的同日未复权OHLC，输出事件事实和覆盖率JSON。去掉 --no-fetch 才会抓取缺失的日OHLC，写入独立的 raw_ohlc_slices 缓存；不发布日报、不下单、不写独立验证通过记录。

每日主流程已使用同一 prepare_limit_event_facts 解释链。每条派生值保留原值、规则版本、源日期/时间与所用OHLC。已知但矛盾的值仍显示冲突；原始归档、股票身份和连板高度不是派生结果。

### 真实9月7日样本验收

| 字段 | 原始规范字段 | 有证据解释后 |
|---|---:|---:|
| 封板尝试 | 0/93 | 93/93 |
| 曾炸板 | 0/93 | 93/93 |
| 回封 | 0/93 | 93/93 |
| 板型 | 0/93 | 93/93 |

上述“0”是原始规范状态未知，不是原始炸板次数等数值缺失。板型为4只一字、89只非一字；57只收盘封板成员有炸板记录。**这57只的样本内回封计数受收盘涨停池筛选影响，绝不能外推成全市场100%回封率。**

## 2. 重算离线报告

~~~powershell
python -X utf8 tools/preview_recap_report.py --audit output/audit/2026-09-07.json --output-dir output/recap-connected --history data/report_prediction_history.jsonl
~~~

输出紧凑复盘、完整看板、嵌入式看板和CSV。预览现在会：

1. 保留审计的成员和嵌入的解释证据；原始归档只用于兼容观测补全。
2. 只读同日OHLC缓存，重新计算事件指标，不再复用旧的零覆盖摘要。
3. 分列“原始观测覆盖 / 规则解释 / 含解释覆盖”，保留收盘样本范围说明。
4. 保持核心质量输入、原始审计与正式历史不变；预览日志只在输出目录追加。
5. 保留既有授权上限。补齐事件字段不等于完成策略验证，更不等于允许实盘开仓。

## 3. 实时盘中输入：先只读采集

~~~powershell
python -X utf8 tools/collect_market_phase.py --output-dir output/live-inputs
~~~

默认不回写历史。每次输出一个JSON及对应HTML摘要，列出真实来源时间、采集时间、覆盖与阻断原因。只消费股票实际价格边界，不用固定涨幅猜ST、创业板或北交所涨跌停。

确需把本次合格观察接入已有预测时，在实际允许时间窗手动使用 --record；例如：

~~~powershell
python -X utf8 tools/collect_market_phase.py --phase early_0935 --record --output-dir output/live-inputs
~~~

这条命令会追加正式阶段/决策历史，**不会下单**。必须有匹配当天目标交易日、在本次观察前发布的预测；采集时、回写前的来源时效与预测版本均须通过。不要把示例日期当作回填参数。

| 阶段 | 上海时间 |
|---|---|
| auction | 09:25–09:29:59 |
| early_0935 | 09:35–09:44:59 |
| confirm_1000 | 10:00–10:15 |
| afternoon | 13:00–14:59:59 |

不存在 --now 或 --captured-at 回填开关。未加 --record 时，即使取得报价，也不更新行动许可。HTML中的行动结论只取回写函数返回的最终decision/readiness，不从旧预测私自重建。没有最终决策时只展示采集事实。

9月9日08:06的真实探测取回5543/5543条报价，源时间仍是9月8日收盘，返回 outside_window，未追加正式历史。这证明入口可采到数据，不代表已经采到了当天早盘数据。当前保存的最新预测面向9月8日，不能绑定9月9日观察。

## 4. 真实样本外验证的未完成边界

截至本轮核查：

- 150个日线切片，2026-01-26至2026-09-07，主要是逐股收盘价，不是分钟级成交序列。
- 阶段历史86条，全部是 close；没有真实竞价/9:35/10点观察。
- 预测90条、市场结果134条；这些不是个股成交笔数。
- 没有可核验的完整交易成交/费用记录，也没有 strategy_validation.json。

因此本轮**没有声称完成交易级样本外验证，没有生成 passed，没有把旧 backtest_pnl_v2_1 的涨跌家数代理当净收益**。要验证“条件确认后下一根可成交分钟线入场、最早T+1退出”等协议，仍需明确并固定入场/退出/费用/滑点/停牌涨跌停处理，并取得真实对应分钟/阶段数据。日线结果或一份数据盘点不能替代这些证据。

本轮未创建自动任务、未发送邮件、未发布正式日报、未修改模型/代理/密钥。
