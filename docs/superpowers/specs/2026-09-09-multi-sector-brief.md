# 多板块盘后简报（已确认方向）
用户认可废弃资格诊断式报告、保留数据层的重做方向，并明确要求多板块、每板块三只、增加最近多板个股。

## 2026-09-10 用户修订（优先于原页面替换安排）
原主报告和原独立看板恢复原布局。多板块观察仅作为独立子页：主页面加入口、子页有返回链接，发布时分别归档，不覆盖主报告/看板。下文关于简报正文和研究排名的要求仍适用于该子页。

## 输出与定义
- 默认前5个有效主线/板块，每板块最多3只，数据足够即3只；板块区股票唯一，不跨板块重复凑数。主板块采用权威行的大主线/primary_sector，不把“其它/未分类”作为推荐板块。
- 板块按涨停家数、连板家数、最高连板高度排序；这是涨停题材热度，不是资金净流入。板块内按连板高度、成交额、封板时间、代码稳定排序，ST/退市股不进入板块三股。
- 最近多板：近5个交易日出现过2连板以上或累计至少2次涨停；分别列当前连板、窗口内最高板、涨停次数、最近涨停日、5日轨迹。今日不在完整涨停池称“今日未涨停”，不擅自称亏损或跌停。ST在专题中保留但显著标记。
- 正文：市场事实/判断 → 多板块三股 → 近期多板专题 → 次日观察。不显示资格审批、AI异常、未发生的盘中确认、缺验证报告等诊断墙。
- 观察排序不依赖plan_permitted/eligible_strategy_ids/独立回测状态；不改变旧的交易许可/成交/持仓/收益接口。新版JSON/CSV明确research_observation，使用独立watchlist文件，不冒充执行池。

## 输入真实性
报告日和权威涨停池必须同日，池大小/成员不可由归档改写；日期/身份/有限正价格需真实。禁止使用未来数据、上日价格充当本日参考价、零代替未知。OHLC仅用同日raw；5日涨幅仅在交易日两端qfq俱全时计算。缺价格的个股不排名；真正缺核心数据时不写出空壳新报告。
保留全部原始数据/审计/两份正式JSONL。补数据只写独立raw OHLC缓存或显式输出目录；不调用AI，不自动下单、创建定时任务或发布邮件。

## 实现边界
research_brief.py纯数据模型；research_brief_io.py只读输入和原子写输出；research_brief_view.py纯HTML；tools/render_research_brief.py提供独立CLI。主入口为独立子页使用新模型和视图，原主报告/看板和交易日志保持既有语义；原旧预览工具保留为开发历史工具。
