# 指数阶段转折领涨模板设计

## 目标

在现有“指数阶段 × 板块共振”模块顶部增加一组固定产品摘要，直接回答：

1. 当前指数处于什么阶段。
2. 最近一次主要转折发生在哪个交易日。
3. 从转折日至报告日，哪些板块和个股领涨。

该模板随每日报告自动更新，不写死日期，不新增外部数据源，也不把口径不同的板块和个股强行归因。

## 统一口径

- **主要转折日**：使用 `detect_phases()` 自动识别的回看窗口最低收盘日，即 `det["bottom"]["date"]`。
- **当前阶段**：使用 `det["shape"]` 的主标签，例如“箱体突破”“箱体震荡”“箱体下沿”“反弹趋势段”或“二次探底”；完整区间和振幅保留为辅助信息。
- **统计终点**：报告日口径下的指数最新有效交易日 `det["latest"]["date"]`。
- **区间收益**：起点和终点均取对应交易日收盘价，计算 `终点 / 起点 - 1`。
- **领涨板块**：复用同花顺行业板块指数，在现有 `底部至今` 列中按区间收益降序取 Top 3。
- **领涨个股**：沪深北全 A 股按区间前复权收益降序取 Top 5；不强制映射到领涨板块。
- **证券名称**：使用报告日证券主数据和项目统一名称解析结果，ST 状态按报告日显示，不沿用陈旧缓存名称。

## 数据架构

### 阶段与板块

`phase_resonance.build_phase_resonance()` 继续负责指数阶段识别和板块区间收益。新增结构化摘要字段：

```python
{
    "current_phase": {
        "label": "箱体突破",
        "detail": "箱体 3768~3941，振幅 4.6%，收在上沿",
        "turning_date": "2026-07-17",
        "latest_date": "2026-08-07",
        "index_return": 4.67,
        "trading_days": 16,
    },
    "turning_leaders": {
        "sectors": [{"name": "贵金属", "return": 35.09}],
        "stocks": [{"code": "sh603221", "name": "爱丽家居", "return": 140.59}],
    },
}
```

### 个股价格

当前历史缓存只有最近交易日完整具备 `close_qfq`，更早记录仍在 `close_legacy`。直接整列选择 `close_qfq` 会导致转折日没有个股样本。

将主报告现有的逐股价格拼接算法提取为共享价格矩阵函数：

1. 优先使用 `close_qfq`。
2. 对同时存在新旧价格的重叠日，计算每只股票的中位缩放比例。
3. 用该比例把 `close_legacy` 历史衔接到前复权口径。
4. 不使用向后填充，避免把首个新价格倒灌到全部历史日期。
5. 北交所缺少可靠复权历史时只纳入能够形成一致区间价格的证券，否则跳过。

主报告原 `_price_matrix()` 保留兼容接口，但委托共享函数计算；`stock_representatives` 复用同一函数，避免形成第二套价格口径。

## 展示设计

摘要放在“指数阶段 × 板块共振”标题和原阶段时间轴之间，使用紧凑、无嵌套卡片的三段布局：

- 左侧：当前阶段、完整阶段细节、转折日期、持续交易日。
- 中间：转折以来领涨板块 Top 3，显示名称和区间涨幅。
- 右侧：转折以来领涨个股 Top 5，显示名称、代码和区间涨幅；ST 使用小标签提示。

桌面端三列，`760px` 以下改为单列。列表使用稳定网格和文本换行，不产生横向溢出。原阶段时间轴、各阶段领涨、四象限和结论继续保留。

## 降级规则

- 阶段识别失败：保持现有行为，整个阶段模块不展示。
- 板块数据不足：保留当前阶段和个股榜，隐藏板块榜，不展示空占位。
- 个股有效覆盖低于证券主数据的 80%：隐藏个股榜，在摘要底部用一行小字提示“区间个股覆盖不足”。
- 单只证券任一端点无一致价格：只跳过该证券，不用零值或单日涨幅替代。
- 名称解析失败：显示规范代码，不使用可能过期的旧名称。
- 任一榜单失败都不得阻断日报和其他阶段分析。

## 测试与验收

### 单元测试

- 当前阶段标签从完整 `shape` 中正确提取。
- 转折日固定取机械识别的主要低点，而不是最新日或见底脉冲终点。
- 板块 Top 3 按 `底部至今` 收益排序。
- 个股 Top 5 使用转折日至报告日的拼接前复权收益排序。
- 名称使用报告日主数据，ST 标签与有效日期一致。
- 覆盖率不足或端点缺失时正确隐藏榜单。

### 渲染测试

- HTML 包含“当前阶段”“主要转折”“转折以来领涨板块”“转折以来领涨个股”。
- 不出现空列表、`None`、`nan` 或技术性数据说明。
- 原阶段时间轴及四象限模块仍存在。
